# Atlas Sanctum

### Intelligence infrastructure for a flourishing planet.

Atlas Sanctum is a technology platform for turning fragmented information about **places, people, infrastructure, ecosystems, and capital** into trustworthy decisions and coordinated action.

We are building an **AI-native regenerative intelligence platform** that helps institutions understand what is happening, determine what matters, decide what to do, coordinate the response, and learn from the outcome.

> **Observe → Understand → Decide → Coordinate → Learn**

Our long-term ambition is to become a **global intelligence infrastructure layer for sustainable development and shared prosperity**, beginning from Africa and building from real places upward.

---

## Why Atlas Sanctum?

The world does not suffer from a lack of information.

It suffers from a lack of systems that can reliably connect:

**Reality → Evidence → Intelligence → Decision → Action → Impact**

Climate risk, infrastructure failure, food insecurity, water stress, disaster response, ecological degradation, public health, logistics, and capital allocation are interconnected problems.

Yet the data needed to understand them is often distributed across:

* satellite and geospatial systems
* weather and climate datasets
* government information
* research institutions
* field observations
* infrastructure inventories
* financial information
* community knowledge
* operational systems

Atlas Sanctum provides a common intelligence layer across these fragmented systems.

The intelligence layer of Atlas Sanctum.

# AI Principles

Atlas Sanctum is not being built around the idea that an AI model should simply produce an answer.

The system must be able to distinguish between:

```text
Information
   ≠
Evidence
   ≠
Inference
   ≠
Prediction
   ≠
Decision
```

Every important intelligence product should increasingly expose:

### Evidence

What observations support the claim?

### Uncertainty

How confident are we?

### Assumptions

What conditions does the analysis depend on?

### Alternatives

What other explanations or interventions exist?

### Consequences

What happens if we act — or do nothing?

### Verification

How can the recommendation be tested?

This is fundamental to trustworthy AI for high-consequence decisions.

# Development Philosophy

Atlas Sanctum follows several engineering principles.

### Build from reality

Begin with real places, real constraints, real users, and real outcomes.

### Evidence before narrative

A compelling story is not a substitute for evidence.

### Systems over silos

The most important opportunities often exist between categories.

### Interoperability over lock-in

The platform should connect to existing systems rather than demand that institutions abandon them.

### Human responsibility

Automation should increase capability while preserving accountability.

### Measure what matters

A beautiful interface is worthless if it cannot improve decisions or outcomes.

### Open where possible

Standards, methodologies, research, and non-sensitive infrastructure should be shareable wherever doing so increases public value.

# Local Development

## Prerequisites

* Node.js 20+
* Python 3.11+
* Git
* Docker
* PostgreSQL-compatible database

Additional dependencies may be required for specific services.

## Clone

```bash
git clone https://github.com/atlasanctum/atlas-sanctum.git
cd atlas-sanctum
```

## Install

```bash
npm install
```

For Python services:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Environment

Create a local environment file:

```bash
cp .env.example .env
```

Configure the required database, authentication, storage, AI, and API credentials.

Never commit secrets.

## Run

```bash
npm run dev
```

For containerized development:

```bash
docker compose up
```
